The written deliverables

ia.md The architecture and why. What was merged, split, added and removed, argued against the twelve intentions — plus every decision the brief left open, with its trade-off stated, and the theme question flagged rather than quietly resolved. markdown
states.md The coverage checklist. Every row of §5 mapped to the file and state where it can be seen, and an explicit line for anything deliberately not designed. markdown
system.css Copied verbatim from the house style system and left unmodified. unchanged
overrides.css Everything added, kept separate so it stays obvious what is new. No hex in any page's markup, so a dark theme remains possible. additions
app.js The state switcher, the currency lens, focus-trapped overlays, and a handful of product behaviours. Vanilla, no framework, no build step. one file
_snippets.md · _agent-brief.md Build notes: the shared page skeleton, the sample data every page holds identical, and the rules each page was written against. Not product documentation. notes

No build step, no framework, no bundler, no network. Every page opens by double-clicking the file.
